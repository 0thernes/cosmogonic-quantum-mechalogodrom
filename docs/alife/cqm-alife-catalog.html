Cosmogonic Quantum Mechalogodrom

A broad browser-based experimental testbed combining simulated ecology, inherited traits, numerical controllers, classical quantum-model calculations and instrumentation. Its integration is the defensible distinction; superiority, consciousness and sustained open-ended evolution remain unestablished.

Current Xylos docs describe recurrent numeric sensing/action and local input replay. Current repository docs also retain failed controls. The report's final appendix records file paths, qualifications and the limits of this static inspection.
